# Team Evidence Table — merged draft

**Research question:** For 20 frozen functional requirements from PURE, how do ChatGPT and Claude using the same one-shot EP–BVA prompt differ in coverage-item percentage relative to a human-designed test suite produced before viewing any AI output?

## Merge rules
- One row per DOI where a DOI is available; DOI duplicates across member tables have been consolidated. Papers without DOI are retained separately unless the title clearly matched.
- Source data and reported values are retained; missing source information is not inferred. `N/A` / `not reported` are preserved where supplied.
- `Gắn RQ` values are copied from member tables where available and are not treated as final inclusion decisions. The current `03_final_included.csv` has no `near_rq` column, so exact CSV-based `near_rq` cannot be populated until that source is updated.
- `⚑` indicates a candidate counterevidence label requiring PL confirmation in RBL-2, not a final inclusion decision.
- Check all status notes and any conflicting figures against `03_final_included.csv` and full text before freezing the final team version.
